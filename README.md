# Next.js Chat Template

A modern AI chat application built with Next.js 14, featuring real-time conversations with multiple AI models.

> English | [简体中文](./README.zh-CN.md)

## 🚀 Features

- 💬 **Real-time Chat** - Streaming responses for smooth conversation flow
- 🤖 **Multiple AI Models** - Support for various AI models
- 📝 **Conversation History** - Save and manage chat sessions
- 🎨 **Modern UI** - Clean, responsive design with Tailwind CSS
- ⚡️ **Next.js 14** - Latest features with App Router
- 🔷 **TypeScript** - Full type safety
- 📱 **Responsive Design** - Works on all devices

## 🏁 Quick Start

### Installation

```bash
# Install dependencies
npm install
```

### Development

```bash
# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

### Build

```bash
# Build for production
npm run build

# Start production server
npm start
```
